WAY TO SHINE — STATIC / NO BUILD VERSION

เวอร์ชันนี้ไม่ใช้ Next.js, npm, React หรือ package ใด ๆ
จึงไม่มีปัญหา build/dependency และเหมาะสำหรับ Vercel แบบ Static.

ไฟล์หลัก: index.html

วิธีใช้กับ Vercel:
1. แตก ZIP
2. อัปโหลดโฟลเดอร์ขึ้น GitHub
3. Vercel > Add New Project > Import GitHub
4. Framework Preset เลือก Other (หรือให้ Vercel ตรวจอัตโนมัติ)
5. Build Command: เว้นว่าง
6. Output Directory: .
7. Deploy

ข้อมูลตัวอย่างและ STAR/TOKEN/Oshi/Kami Oshi เก็บใน browser localStorage
Login เป็น demo เท่านั้น
